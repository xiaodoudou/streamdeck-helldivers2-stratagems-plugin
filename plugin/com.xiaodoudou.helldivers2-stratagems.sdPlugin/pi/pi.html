Nth stratagem read from the game, in order of appearance. Scan period, keys and timings are shared by all keys: set them on the Scan Now key.
Stratagems of your loadout, numbered in the order you chose them: 1 is the first. They are found in the stratagem menu wherever they are, even when a mission adds stratagems of its own before them. A press calls each one in, in this order, and throws it before the next; one that isn't ready is skipped. It needs the Throw input, set on the Scan Now key.

Scanning

Auto scan off: only the Scan Now key reads the game. Confirm after: scans in a row a stratagem must be seen before it is added. Icon scale: only for a non-default HUD scale. Game resolution: auto measures the game window; type a size (2560x1440) only if the size found is wrong.

Inputs (click, then press a key or mouse button)

Match your key bindings in the game. Throw is the key or button you throw a stratagem with: Stratagem Setup keys always throw, and the slot keys too when Throw after calling in is ticked. Backspace clears the throw key while capturing.
